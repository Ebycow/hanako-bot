# OGP画像の生成

SNS や Discord で URL を共有したときに出る画像（`public/assets/og-2.jpg`）を作る。
`make-og.mjs` は、背景（ピンクのグラデーションと白い水玉）を描き、左に透過のキャラ素材 `character.png`、右にロゴと説明の文字を重ねて 1200×630 にする。

## 使い方

```sh
npm install
node tools/og-image/make-og.mjs
```

- 引数を省くと、`tools/og-image/character.png` から `public/assets/og-2.jpg` を作る。別の素材を使うときは `node tools/og-image/make-og.mjs キャラ.png 出力先.jpg`。
- キャラの大きさと位置は `character`、文字の内容・大きさ・位置・色は `cx` / `logo` / `lines`、背景の色や水玉は `background` で変える。どれも `make-og.mjs` の中にある。
- フォント（Zen Maru Gothic の Black と Bold）は、初回に `tools/og-image/fonts/` へ自動で取ってくる（Git には入れない）。
- 画像の加工には、Astro に付いてくる `sharp` を使う。文字をパスにするのに `opentype.js`（devDependencies）を使う。

## 画像を差し替えるとき

Discord や X は、一度読み込んだ画像をしばらくキャッシュする。同じファイル名で上書きすると、古い画像が出続けることがある。
公開済みの画像を差し替えるときは**ファイル名を変えて**（例: `og-3.jpg`）、`make-og.mjs` の出力先と `src/layouts/BaseLayout.astro` の `ogImage` を直し、古いファイルは消す。

## キャラ素材を作り直すときの目安

- **キャラだけを、正方形の透過PNGで作る。** 背景や横長のレイアウトまで生成AIに描かせると、背景にノイズが乗って粗く見えた。背景と文字はこのスクリプトで描くほうがきれいになる。
- 上半身を大きく。胸元あたりで切れていてよい（素材の下端を画像の下端にそろえるので、切れ目は見えない）。
- 実際は横 400px くらいの小ささで見られる。顔をはっきり描き、細い線や細かい小物は控えめにする。
- 「読み上げ」が伝わる要素を入れる（ヘッドセットのマイク、音符、呼びかけるしぐさなど）。Discord のロゴは入れない。
- 文字やロゴは描かせない（生成AIの日本語は崩れやすいので、文字はこのスクリプトで重ねる）。

## ハマりどころ

- **SVG の `<text>` で文字を書くと、フォントが反映されない。**
  sharp（librsvg）は、システムに入っているフォントしか使えない。`font-family` に Zen Maru Gothic を指定しても、ヒラギノなど別のゴシック体で描かれる。
  sharp の `text` 入力に `fontfile` を渡す方法も、macOS では fontconfig の設定ファイルが見つからず、同じように別の書体になった。
  そこで、opentype.js でフォントファイルから文字の形（パス）を取り出し、`<path>` として描いている。
- **生成AIの透過素材は、体の不透明度が 255 になっていないことがある。**
  今の素材は体の部分が 252〜253 で、ふちの外にもごく薄いもや（1〜19）が広がっていた。そのまま重ねると、背景がわずかに透けたり、ふちが曇ったりする。
  重ねる前に、240 以上を 255 に、12 未満を 0 にそろえている。
- **PNG で書き出すと 1MB を超える。**
  JPG（品質 88）にすると 100KB くらいに収まる。
