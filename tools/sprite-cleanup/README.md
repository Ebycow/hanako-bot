# 切り出し画像の「隣のコマの断片」除去

画像生成で作ったスタンプシートや表情差分シートを 1 コマずつ切り出すと、隣のコマの髪先などが端に細く残ることがよくある。
`clean_edges.py` は、透過 PNG／WebP からこの断片だけを消すスクリプト。

## 使い方

```sh
python3 -m venv .venv && .venv/bin/pip install pillow numpy scipy
.venv/bin/python tools/sprite-cleanup/clean_edges.py public/assets/hanako-*.webp --out /tmp/cleaned --diff /tmp/diff
```

- `--out` に修正後の画像を出力する（元画像は上書きしない）。断片がなかった画像は出力しない。
- `--diff` には、消した範囲を赤く塗った PNG を出力する。差し替える前に必ずこれを目で確認する。赤い部分が画像の端にしかなければ問題ない。
- 確認できたら、`--out` の画像を元の場所へコピーする。

## 考え方

断片は「本体とつながっていない」「画像の端に触れている」「小さい」の 3 つを満たす。
装飾（ハートや音符など）は本体とつながっていないが端には触れていないので、残る。

## 手順

1. **強い不透明画素で連結成分を作る**
   アルファ > 64 の画素だけを対象に、8 近傍でラベリングする（`scipy.ndimage.label`）。
   いちばん大きい成分を本体とみなす。
2. **断片を判定する**
   本体以外の成分のうち、画像の外周 3px に触れていて、面積が本体の 10% 未満のものを断片とする。
3. **断片の半透明部分まで広げる**
   アルファ > 8 の画素から「残す成分を 2px 膨張させた範囲」を除き、その中で断片とつながっている領域を削除対象に加える。
   こうすると、断片の薄い毛先まで消せて、本体の縁には入り込まない。
4. **断片の縁のにじみを消す**
   削除対象を 2px 膨張させ、そこにあるアルファ > 0 の画素も消す。ただし、残す成分から 1px 以内の画素は消さない。

## ハマりどころ

- **アルファ > 0 でラベリングすると失敗する。**
  生成画像はふちに薄い半透明のにじみがあり、断片と本体がそれでつながって 1 つの成分になってしまう。
  実際、この方法では大きな断片が残った。強い不透明画素だけで判定するのが肝心。
- **「本体の近く以外は全部消す」方式は危ない。**
  背景にほぼ透明なノイズや本体の柔らかい縁があり、それまで消えて見た目が変わる。
  消す範囲は「断片から伸ばした部分」に限定する。
- **装飾が端に触れている場合は誤って消える。**
  `--diff` で確認し、必要ならその画像だけ除外する。
- **大きすぎる断片は残る。**
  断片が本体の 10% 以上あるときは別のキャラが写り込んでいる可能性が高く、切り出し位置からやり直したほうがよい。

## パラメータ

`clean()` の引数で調整できる。

| 引数 | 既定値 | 意味 |
| --- | --- | --- |
| `alpha_strong` | 64 | 連結判定に使う不透明度のしきい値。にじみが濃い画像では上げる |
| `alpha_weak` | 8 | 断片の半透明部分として扱う下限 |
| `edge` | 3 | 「端に触れている」とみなす外周の幅（px） |
| `max_ratio` | 0.1 | 本体に対する面積比がこれ未満なら断片とみなす |

## 実績

2026-10 に、`public/assets/hanako-*.webp`（512×512 の表情差分）18 枚に適用した。14 枚で断片を除去し、4 枚は断片なしだった。
