STEP 01 — GETTING STARTED

たった4ステップで、はじめよう。

TL;DR

ボイスチャンネルに入って /plz。以上です。

結論から言うと、Hanakoは「あなたがいるボイスチャンネル」に参加し、「呼ばれたテキストチャンネル」を読み上げます。複雑な設定は一切不要。驚くほどシンプルです。

STEP 1 ボイスチャンネルに入る 先にあなたが参加しておく
STEP 2 /plz と打つ 読んでほしいテキストチャンネルで
STEP 3 ✨ Hanakoが参加 そのチャンネルの発言を読み上げる
STEP 4 /bye で退出 誰もいなくなれば自動で退出

図：読み上げ開始から終了までのユーザージャーニー

🚀 知っておきたい4つのパワー機能

  • マルチチャンネル対応：Hanakoが参加中に、別のテキストチャンネルでもう一度 /plz を打つと、そのチャンネルも読み上げ対象に加わります。
  • ボイスチャンネル内チャットにも対応：ボイスチャンネルに付いているテキストチャットで /plz を打てば、そこが読み上げ対象になります。
  • スマート自動退出：ボイスチャンネルにHanakoだけが残ると、自動で退出します。リソースの無駄は一切ありません。
  • 自動再接続：メンテナンスで再起動したときは、元のボイスチャンネルに自動で再接続し、読み上げを再開します。
対応していない場所 スレッド、フォーラム、アナウンスチャンネルは読み上げできません。ステージチャンネルにも参加できません。
STEP 02 — INPUT METHODS

あなたに最適な、3つの入力体験。

同じコマンドを3通りの書き方で実行できます。ワークフローに合わせて、自由に選択しましょう。迷ったら、スラッシュコマンドがおすすめです。

🔥 おすすめ

スラッシュコマンド

/teach from:草 to:くさ

入力欄に / を打つと候補と説明が出ます。引数の名前が表示されるので打ち間違えにくく、一覧系の結果は自分にだけ表示されます。

テキスト

メンション

@はなこ teach 草 くさ

Hanakoにメンションして、コマンド名と引数をスペース区切りで続けます。日本語の別名（教育 など）も使えます。

テキスト

プリフィックス >

>teach 草 くさ

発言の先頭に > を付けます。最小のキーストロークで最大の成果を。

Pro Tip：読まれたくない発言は > で始めよう > で始まる発言は、コマンドとして存在しない内容でも読み上げられません。独り言やメモに最適な、まさに「隠れた神機能」と言えるでしょう。

📊 スラッシュ vs テキスト：徹底比較

スラッシュコマンド テキストコマンド
一覧・検索・ヘルプの結果 自分にだけ見える チャンネルの全員に見える
全削除の確認 「実行する」ボタンを押す コマンドに --force を付ける
SEを複数まとめて追加・削除 1件ずつ まとめてできる
使える人の決まり方 サーバー管理者が自由に変更できる 固定（08章を参照）
サーバーごとに無効化 できない /text-commands で無効にできる
STEP 03 — UNDER THE HOOD

声が生まれる、5つのステージ。

発言は、声になるまでに5段階の高度なパイプラインを通過します。「なぜこう読まれたのか」「なぜ読まれなかったのか」——その答えは、すべてこの順番の中にあります。

  1. 読むかどうかを決める 読み上げ対象チャンネルの、人間の発言だけを通します（下の表を参照）。
    HIKAKINの動画見た https://youtu.be/abc （拍手）
  2. 読める形に直す URLは「URL」に、メンションは表示名に、絵文字は名前に置き換えます。
    HIKAKINの動画見た URL （拍手）
  3. 辞書で読み替える 教育した単語を置き換えます。SEのキーワード部分は書き換えません。
    ヒカキンの動画見た URL （拍手）
  4. 長すぎたら切る 文字数制限を超えた分を切り捨て、最後に「イか略。」と読みます。
    ヒカキンの動画見た URL （拍手）
    // 制限内なのでそのまま
  5. 声とSEに分けて再生する SEのキーワードは効果音に、それ以外は合成音声になり、順番に再生されます。
    🗣 ヒカキンの動画見た URL 🎺 （拍手）

例：辞書に「HIKAKIN → ヒカキン」、SEに「（拍手）」を登録しているサーバーでの読み上げ

🚫 読み上げられない発言

発言 理由・対処
読み上げ対象でないチャンネルの発言 そのチャンネルで /plz を打つと対象に加わります
> で始まる発言、Hanakoへのメンション コマンドとして扱うため読みません
ほかのBotの発言 常に読みません
ブラックリストに入っている人の発言 07章を参照
画像やファイルだけの発言 本文がないので読みません
記号や空白だけの発言 声にできる文字がないので読みません
スレッド・フォーラム内の発言 対応していません

⚔️ 読み上げを止める：成敗

長文やSEが流れ続けて困ったときは /seibai。いま読んでいる音声と、その後ろで順番待ちしている音声をすべて中断します。Hanakoは退出しないので、次の発言からまた読み上げます。

STEP 04 — SMART DICTIONARY

読み間違い、ゼロの世界へ。

読み間違える単語や、内輪の呼び名の読み方を教える機能です。サーバーごとに200件まで覚えます。あなたのコミュニティの「文化」を、Hanakoに学ばせましょう。

INPUT 発言 「電ちゃんかわいい」
PROCESS ✨ 辞書 電 ⇨ いなづま
OUTPUT 読み上げ 「いなづまちゃんかわいい」

発言の中に含まれる単語を、読み上げる直前に置き換えます（発言そのものは変わりません）

やりたいこと コマンド
単語を教える /teach from:置換前 to:置換後
単語を忘れさせる /forget from:置換前
覚えている単語を見る /dictionary（ボタンでページ送り）
すべて忘れさせる /dictionary-clear（サーバー管理の権限が必要）

🎯 押さえておきたい重要なポイント

  • 置換前・置換後とも2〜50文字。1文字の単語は登録できません。
  • 同じ「置換前」は1つだけ。読み方を変えたいときは、いちど /forget してから教え直します。
  • 単語の一部にも反応します。短い単語を登録すると、思わぬ言葉の中で置き換わることがあります。
  • SEのキーワードになっている部分は、辞書では置き換えません（SEが優先されます）。
STEP 05 — SOUND EFFECTS

会話に、没入感という魔法を。

キーワードに音声ファイルを結びつけると、その言葉が発言に出てきたとき、読み上げの代わりに音を鳴らします。テキストチャットが、まるでライブ会場のように生まれ変わります。

➕ 追加する：3つの柔軟な方法

スラッシュ / テキスト

URLで指定

/se-add keyword:（拍手） url:https://…/clap.mp3

ネット上の音声ファイルのURLを指定します。URLは300文字まで。

スラッシュ / テキスト

ファイルを1つ添付

/se-add keyword:（拍手） ＋ file に添付

手元のファイルをそのまま登録できます。テキストなら @はなこ se-add （拍手） に添付。

⚡ バッチ処理

複数ファイルをまとめて

@はなこ se-add ＋ 複数ファイルを添付

キーワードを書かずに添付すると、ファイル名（拡張子を除く）がそのままキーワードになります。テキストコマンドのみ対応。

📋 技術仕様

形式 .wav / .mp3
サイズ 1ファイル 2MB まで
長さ 60秒 まで
キーワード 2〜49文字（同じキーワードは1つだけ）
登録数 サーバーごとに 10,000件 まで
ベストプラクティス：キーワードは記号で囲もう SEは発言の一部にも反応します。「草」のような短い言葉を登録すると、「草原」でも鳴ります。（拍手） や :clap: のように、ふだんの会話に出てこない形にしておくと誤爆しません。

🔍 探す・直す・消す

やりたいこと コマンド 補足
一覧を見る /se-list ボタンでページ送り
うろ覚えで探す /se-search keyword:拍手 完全一致 → 前方一致 → 部分一致の順に、近いものを5件まで表示。見つからなければ打ち間違いも考慮して探します
キーワードを変える /se-rename old_keyword:旧 new_keyword:新 音声はそのまま、名前だけ変更
消す /se-del keyword:（拍手） テキストなら @はなこ se-del A B C で複数まとめて削除

🎚️ 音量をそろえる：SE正規化

SEはファイルごとに音量がばらばらです。正規化をオンにすると、小さすぎるSEを指定したレベルまで持ち上げて、聞こえ方をそろえます。まさに、音量のイコライゼーションです。

Before：正規化なし（0）
目標 80
SE ASE BSE C
After：/se-normalize level:80
目標 80
SE ASE BSE C

小さいSEが目標レベルまで持ち上がります（イメージ図）

  • /se-normalize level:0〜100 で設定します。初期値は 50、0 で無効です。
  • サーバー全体の設定です。変更には「サーバー管理」の権限が必要です。
STEP 06 — PERSONALIZATION

声と、読む長さの設定。

「誰の声で」「どこまで」読むかの設定です。効く範囲がそれぞれ違うので注意してください。

👤 自分だけに効く

キャラクター変更

/speaker name:キャラクター名

あなたの発言を読む声を変えるコマンドです。ほかの人の声は変わりません。設定はサーバーごとに覚えます。

現在使える声は default の1種類だけなので、実質的には変更できません。

🌐 サーバー全体に効く

文字数制限

/limit number:30

1つの発言で読む文字数の上限です（0〜2000）。超えた分は読まず、最後に「イか略。」と付けます。

/limit number:0 で無制限（初期値）。変更には「サーバー管理」の権限が必要です。

使えるキャラクター名（現在1種類） いま使えるのは default（既定の声）だけです。ほかの名前を指定すると読み上げに失敗することがあるので、その場合は /speaker name:default で戻してください。
STEP 07 — TRUST & SAFETY

安心・安全を、デフォルトに。

特定のユーザーの発言を読み上げないようにする機能です。Discord上のミュートやタイムアウトとは別で、Hanakoが「その人の発言を読まない」だけです。

やりたいこと コマンド 必要な権限
読まないようにする /blacklist-add user:@ユーザー メンバーをタイムアウト
解除する /blacklist-remove user:@ユーザー メンバーをタイムアウト
一覧を見る /blacklist-show メンバーをタイムアウト
全員を解除する /blacklist-clear サーバー管理
  • その人がコマンドを使うことは妨げません。止まるのは読み上げだけです。
  • ほかのBotの発言はもともと読まないので、登録は不要です。
STEP 08 — ACCESS CONTROL

柔軟で堅牢な、権限マネジメント。

ほとんどのコマンドは誰でも使えます。影響の大きいものだけ、Discordの権限でしっかりと守られています。

👥 だれでも 権限は不要
/plz /bye /seibai /teach /forget /dictionary /se-add /se-del /se-list /se-search /se-rename /speaker /help /ask
🛡️ モデレーター 「メンバーをタイムアウト」
/blacklist-add /blacklist-remove /blacklist-show
👑 サーバー管理者 「サーバー管理」
/limit /se-normalize /dictionary-clear /blacklist-clear /text-commands

コマンドを使える人の初期設定。「管理者」権限を持つ人はすべて使えます

⚙️ 使える人を変える

上の図は初期設定です。サーバー管理者は、Discordの「サーバー設定 → 連携サービス → はなこ」から、コマンドごとに使えるロール・メンバー・チャンネルを変更できます（例：ブラックリストを全員が使えるようにする、/se-add を特定のロールだけにする）。

注意：この変更はスラッシュコマンドにしか効きません @はなこ や > で打つテキストコマンドは、つねに上の図の初期設定で判定されます。連携サービスで細かく制限したいサーバーは、次のコマンドでテキストコマンドを止めてください。

🔌 テキストコマンドを止める

/text-commands enabled:False を実行すると、そのサーバーでは @はなこ や > で始まるコマンドに反応しなくなります（enabled:True で元に戻ります）。

  • 止めている間、テキストコマンドには案内も返さず、黙って無視します。
  • > で始まる発言を読み上げない動作は、そのまま変わりません。
  • > をほかのBotのコマンドに使いたいサーバーにも向いています。

🔑 Hanako自身に必要な権限

Hanakoが動くには、対象のチャンネルで次の権限が必要です。足りないときは、Hanakoがどの権限が足りないかを教えてくれます。

場所 権限
ボイスチャンネル チャンネルを見る／接続／発言
テキストチャンネル チャンネルを見る／メッセージを送信／埋め込みリンク／メッセージ履歴を読む／リアクションの追加

🔒 データはサーバーごとに完全分離

辞書・SE・ブラックリスト・各種設定は、Discordサーバーごとに別々に保存されます。ほかのサーバーの設定が混ざったり、見えたりすることはありません。保存する情報の詳細はプライバシーポリシーをご覧ください。

STEP 10 — FAQ

よくある質問と、その解決策。

お困りですか？ご安心ください。Hanakoの返事や症状から、原因と対処をすばやく特定できます。

🙋 Hanakoが来ない

「通話チャンネルに参加してから呼んでね！」と言われる

あなたがボイスチャンネルに入っていません。先にボイスチャンネルに参加してから /plz を打ってください。

「〜の権限がないみたい…」と言われる

そのボイスチャンネルで、Hanakoに「チャンネルを見る」「接続」「発言」のいずれかが許可されていません。返事に足りない権限の名前が出るので、サーバーの管理者にチャンネルの権限設定を確認してもらってください。

「満員で入れないよ」「タイムアウト中だから入れないよ」と言われる

ボイスチャンネルの人数制限に達しているか、Hanako自身がタイムアウトされています。人数制限を広げるか、Hanakoのタイムアウトを解除してください。

「ステージチャンネルには参加できないの」「このチャンネルは読み上げに対応していないの」と言われる

ステージチャンネルへの参加と、スレッド・フォーラムなどの読み上げには対応していません。通常のボイスチャンネルに入り、通常のテキストチャンネル（またはボイスチャンネル内のチャット）で呼んでください。

🔇 読んでくれない・読み方がおかしい

自分の発言だけ読まれない
  • ブラックリストに入っていないか、モデレーターに /blacklist-show で確認してもらってください。
  • 発言が > で始まっていないか確認してください。
  • /speaker で存在しないキャラクター名を設定していると読めません。/speaker name:default で戻してください。
このチャンネルの発言が読まれない

Hanakoは /plz を打ったチャンネルだけを読みます。読んでほしいチャンネルで、もう一度 /plz を打ってください。スレッドの中は読めません。

途中で切れて「イか略。」と言う

文字数制限にかかっています。サーバー管理者が /limit number:0（無制限）か、より大きい数字に設定し直せます。

変なところで言葉が置き換わる・SEが鳴る

辞書もSEも、単語の一部に反応します。/dictionary や /se-search で原因の登録を探し、/forget・/se-del で消すか、/se-rename で記号つきのキーワードに変えてください。

読み上げが止まらない・たまりすぎた

/seibai で、再生中と順番待ちの音声をすべて中断できます。何も読んでいないときに打つと「安心せい、みねうちにゃ…」と返ります。

⛔ コマンドが使えない

「このコマンドは『〜』の権限を持っている人だけが使えるよ」と言われる

そのコマンドには権限が必要です（08章の図を参照）。権限を持っている人に頼むか、サーバー管理者に使える人の設定を変えてもらってください。

@はなこ や > のコマンドに何も反応しない
  • サーバーでテキストコマンドが無効になっている可能性があります。スラッシュコマンドを使うか、サーバー管理者に /text-commands enabled:True を実行してもらってください。
  • コマンド名を打ち間違えると、Hanakoは何も返しません（> で始まる独り言と区別できないためです）。
スラッシュコマンドの候補に出てこない

権限がないコマンドは、Discordが候補から隠します。また、スラッシュコマンドはサーバー内でのみ使えます（HanakoとのDMでは使えません）。

🎵 SEを登録できない

「これサウンドファイルじゃなさそう」「変換できなかったにゃ」と言われる

対応しているのは .wav と .mp3 です。動画ファイルや別形式の音声は、mp3 か wav に変換してから登録してください。URLで指定する場合は、再生ページではなく音声ファイルそのもののURLが必要です。

「〜秒より長い音声は登録できないにゃ」と言われる／大きいファイルが登録できない

SEは60秒・2MBまでです。短く切るか、ビットレートを下げてから登録してください。

「すでに登録済みのキーワードです」「一文字登録はできません」と言われる

キーワードは2〜49文字で、サーバー内で重複できません。音を差し替えたいときは、先に /se-del で消してから登録し直します。

🤝 それでも解決しないとき

Hanakoを招待してくれた人に聞いてみてください。Bot本体の不具合と思われる場合は、GitHub の Issueに投稿すると、ほかの利用者の助けにもなります。
