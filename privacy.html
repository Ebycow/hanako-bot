プライバシーポリシー

利用者のプライバシーをいちばんに考えています。Hanakoが扱う情報について、ここで説明します。

このプライバシーポリシー（以下「本ポリシー」）は、Ebycow（以下「運営者」）が運営・提供する Discord Bot「Hanako」（以下「本Bot」）が取り扱う情報と、その利用目的・保存・削除について説明するものです。

Hanako のソースコードは公開されており、運営者以外の第三者が独自に運営している Bot（以下「第三者Bot」）が存在する場合があります。本Botの範囲は利用規約第1条に定めるとおりです。本ポリシーは第三者Botには適用されません。運営者は第三者Botが取り扱う情報を保有・管理しておらず、その開示・削除などの請求にも対応できません。第三者Botについては、当該Botの運営者にお問い合わせください。

1. 取り扱う情報

本Botは、機能の提供のために以下の情報を取り扱います。

情報内容保存
メッセージの内容読み上げ対象チャンネルに投稿されたメッセージの本文、および本Botへのコマンドの本文（コマンドは読み上げ対象以外のチャンネルでも受け付けます）。音声合成とコマンド処理のために使用します。保存しません（動作ログにも本文は記録しません。下記3を参照）
サーバー・チャンネル情報サーバーID、サーバー名、チャンネルID、チャンネル名。サーバーIDは各設定の識別子として保存します。接続中のボイスチャンネルID・読み上げ対象チャンネルIDは、本Botの再起動時に限り、復帰のために一時的に保存します
ユーザー情報ユーザーID、表示名。ブラックリストに追加されたユーザーのIDと追加日時、および読み上げキャラクターを変更したユーザーのIDを保存します
辞書利用者が「教育」コマンドで登録した置換前・置換後の単語。サーバーごとに保存します
SE（効果音）利用者が登録したキーワード、音声ファイルのURL、および取得した音声ファイル。サーバーごとに保存します
サーバー設定読み上げ文字数の上限、ユーザーごとの読み上げキャラクター、SE音量の正規化レベル、テキストコマンドの有効・無効。サーバーごとに保存します

本Botは、Discord の仕組み上、本Botが閲覧できるチャンネルに投稿されたメッセージを受信します。本Botに「チャンネルを見る」権限がないチャンネルのメッセージは、Discord から本Botに届かないため、受信もしません。サーバーの管理者は、チャンネルやカテゴリの権限設定で本Botが閲覧できるチャンネルを絞り込めます（絞り込んだチャンネルでは、読み上げやコマンドは使えなくなります）。

受信したメッセージのうち、読み上げ対象ではないチャンネルに投稿された、コマンド以外のメッセージは、受信した時点で破棄し、処理・保存しません。ダイレクトメッセージも処理・保存しません。ボイスチャンネルにはスピーカーミュートの状態で参加し、ボイスチャンネル内の音声（利用者の声）は受信しません。

2. 利用目的

取り扱う情報は、以下の目的にのみ利用します。

  • メッセージの読み上げ、および各コマンド機能の提供
  • サーバーごとの辞書・SE・ブラックリスト・設定の保持
  • 再起動時に読み上げ状態を復帰させるため
  • 障害の調査、不具合の修正、不正利用への対応

3. 動作ログ

本Botは、障害調査のために動作ログを記録します。ログには、メッセージの本文、コマンドに入力された文字列（辞書の単語、SEのキーワード、添付ファイルの名前などを含みます）、投稿者のユーザー名、サーバー名、チャンネル名を記録しない方針としています。

ログに記録されるのは、主に以下の運用情報です。

  • メッセージID、サーバーID、チャンネルID、ボイスチャンネルID、投稿者のユーザーID
  • メッセージの文字数、コマンドの種類と引数の個数、処理結果やエラーの種別
  • メッセージ内でメンションされたユーザーのID
  • 辞書・SEなどの登録データのID
  • エラーの種別と内容（SEの音声ファイルの取得に失敗した場合は、取得先のホスト名と、クエリ部分を除いたURLを含むことがあります）

ログは日付ごとのファイルとして運営者のサーバー内に保存されます。障害や不正利用をあとから調査できるよう、動作ログは90日、エラーログは1年を経過したものから自動的に削除します。ログは障害調査および不正利用への対応以外の目的では閲覧しません。

4. 第三者への提供・外部送信

  1. 読み上げるメッセージの本文（辞書による置換・整形後のテキスト）は、音声を生成するために音声合成サーバーへ送信されます。音声合成サーバーは運営者が管理しており、送信されるのはテキストとキャラクター名のみで、ユーザーIDなどの識別情報は含まれません。
  2. SEを登録する際、本Botは利用者が指定したURLへアクセスして音声ファイルを取得します。
  3. 上記のほか、法令に基づく場合を除き、取り扱う情報を第三者に提供・販売することはありません。
  4. 本BotはDiscord上で動作するため、Discordを通じてやり取りされる情報には Discord Inc. のプライバシーポリシーが適用されます。

5. 保存期間と削除

  • 辞書・SE・ブラックリスト・サーバー設定は、利用者が削除するか、運営者が本Botの提供を終了するまで保存されます。
  • 辞書は /forget（全削除は /dictionary-clear）、SEは /se-del、ブラックリストは /blacklist-remove または /blacklist-clear で、サーバーの利用者自身が削除できます（一部のコマンドには「サーバー管理」などの権限が必要です）。
  • ボイスチャンネル・読み上げチャンネルの復帰用情報は、本Botの停止時に保存され、再起動後の復帰処理が完了した時点で削除されます。
  • 本Botをサーバーから退出させた後に、そのサーバーのデータをすべて削除したい場合、または開示を希望する場合は、お問い合わせフォームから請求してください（下記9を参照）。第三者による削除を防ぐため、フォームからの削除の請求は、本Botを退出させたサーバーについてのみ受け付けます。本Botが導入されているサーバーのデータは、上記のコマンドで削除してください。

6. 安全管理

取り扱う情報は、運営者が管理するサーバー内に保存し、不正アクセス、漏えい、滅失などを防ぐために必要かつ適切な措置を講じるよう努めます。

7. 本ウェブサイトについて

本ウェブサイトは、Cookie やアクセス解析ツールを使用していません。

ただし、本ウェブサイトは以下の外部サービスを利用しているため、閲覧すると、閲覧者のIPアドレスやブラウザの情報（User-Agent など）が各サービスの提供元に送信されます。これらの情報は各提供元のプライバシーポリシーに従って取り扱われ、運営者が受け取ることはありません。

  • GitHub Pages（GitHub, Inc.）：本ウェブサイトの配信に利用しています。GitHub のプライバシーステートメント
  • Google Fonts（Google LLC）：文字のフォントの配信に利用しています。Google のプライバシーポリシー

8. 本ポリシーの変更

運営者は、必要に応じて本ポリシーを変更することがあります。変更後のポリシーは、本ページに掲載した時点から効力を生じます。

9. お問い合わせ

  • サーバーデータの削除・開示の請求、SE音源の権利侵害の申立：お問い合わせフォーム（Googleフォーム）から受け付けます。対象のサーバーIDを入力してください。個人データに関するご質問も同じフォームで受け付けます。開示の請求、ご質問、権利侵害の申立への回答には連絡先（DiscordのIDやメールアドレスなど）が必要です。削除の請求だけであれば、連絡先の入力は不要です。いただいた連絡先は、その請求・申立への回答にのみ使用します。送信内容は Google のサービス上で運営者が管理します。
  • その他のお問い合わせ：GitHub の Issueまでお願いします。Issue は公開の場ですので、個人情報を書き込まないようご注意ください。
